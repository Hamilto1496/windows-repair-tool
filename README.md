## ⚙️ What This Tool Does

Your Windows computer relies on thousands of system files to run smoothly. Sometimes these files get corrupted—due to updates, crashes, malware, or power outages—causing errors like:

- Blue Screen of Death (BSOD)
- Programs not opening or crashing
- Slow performance
- Windows Update failures
- Random system freezes

This tool fixes those problems by running two built-in Windows commands:

### 🔍 SFC (System File Checker)
This command scans all protected system files and replaces corrupted ones with healthy versions. It's like a doctor checking every organ in your body and fixing anything that's broken.

### 🧪 DISM (Deployment Imaging Service and Management)
This command repairs the underlying Windows image—the "blueprint" your system files come from. If SFC can't fix something because the source files are damaged, DISM repairs the source first, allowing SFC to succeed.

**Together, they fix nearly all common Windows file corruption issues.**

## 🔧 How It Works Under the Hood (Simple Explanation)

Windows keeps a special "system image" that contains all the original system files. When your computer gets corrupted:

1. **DISM** checks and repairs this system image first, like fixing the master mold used to create parts.
2. **SFC** then compares your current system files to the repaired image and replaces any mismatched or corrupted ones.

This two-step process handles virtually all corrupted file scenarios.
